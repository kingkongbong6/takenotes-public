# Инструкция по выполнению практической работы №2 на macOS

<sub>[← К предмету](../README.md) · [Все предметы](../../README.md)</sub>

[← К описанию практической работы](%D0%9F%D1%80%D0%B0%D0%BA%D1%82%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B0%D1%8F%20%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0%20%E2%84%962%20%E2%80%94%20Microsoft%20Word%20%D0%BA%D0%B0%D0%BA%20%D1%80%D0%B0%D0%B1%D0%BE%D1%87%D0%B0%D1%8F%20%D1%81%D1%80%D0%B5%D0%B4%D0%B0.md)

Эта инструкция предназначена для настольной версии Microsoft Word на macOS. Выполняйте пункты сверху вниз и отмечайте каждое завершённое действие.

> [!IMPORTANT]
> **Important**
> Навигационный документ используется только как материал для упражнений. Не сохраняйте в нём экспериментальные изменения. Если команда отсутствует, не ищите опасный обходной способ: запишите это как отличие версии Word.

## Как заполнять паспорт

В начале паспорта создайте раздел «Сведения о выполнении»:

| Поле | Что записать |
| --- | --- |
| ФИО | Фамилия, имя и отчество |
| Группа | Номер или название группы |
| Дата | Дата выполнения в формате ДД.ММ.ГГГГ |
| Операционная система | macOS и номер версии |
| Word | Выпуск, версия и номер сборки |
| Язык интерфейса | Русский, английский или другой |

После каждого шага добавляйте подзаголовок «Шаг N» и фиксируйте результат в указанном ниже виде. Если функция отсутствует, пишите: **«Не обнаружена в Word версии … на macOS …»**.

## Шаг 1. Подготовить папки и паспорт

- [ ] Откройте Finder.
- [ ] Создайте папку **WORD_PRO_ФамилияИмя**.
- [ ] Внутри создайте **Блок_01**, а в ней — папки **ПР01** и **Resources**.
- [ ] Скопируйте [навигационный документ](%D0%9B%D0%B5%D0%BA%D1%86%D0%B8%D1%8F3_%D0%9D%D0%B0%D0%B2%D0%B8%D0%B3%D0%B0%D1%86%D0%B8%D0%BE%D0%BD%D0%BD%D1%8B%D0%B9_%D0%B4%D0%BE%D0%BA%D1%83%D0%BC%D0%B5%D0%BD%D1%82_%D0%AD%D0%94%D0%9E.docx) в Resources.
- [ ] Откройте Word и нажмите **⌘N** либо выберите **File → New Blank Document**.
- [ ] Введите заголовок «Паспорт рабочей среды Microsoft Word».
- [ ] Нажмите **⌘S** и сохраните документ в ПР01 под именем **ПР01_Паспорт_среды_Фамилия.docx**.
- [ ] Закройте паспорт через **⌘W**, откройте его снова и убедитесь, что файл сохранился.

**В паспорт:** заполните таблицу «Сведения о выполнении». Поля версии Word пока можно оставить пустыми.

## Шаг 2. Определить версию Word

- [ ] В верхней строке меню macOS выберите **Word → About Microsoft Word**.
- [ ] Найдите название выпуска, номер версии и тип лицензии.
- [ ] При необходимости откройте **Help → Check for Updates** и запишите номер сборки.
- [ ] Закройте информационное окно без изменения настроек.

**В паспорт запишите одной строкой:**

> Microsoft Word: [выпуск], версия [номер], сборка [номер], язык интерфейса [язык].

## Шаг 3. Открыть исходный документ разными способами

- [ ] Способ 1: выберите **File → Open**, найдите Resources и откройте DOCX.
- [ ] Закройте только документ сочетанием **⌘W**.
- [ ] Способ 2: нажмите **⌘O** и откройте тот же файл.
- [ ] Снова закройте документ.
- [ ] Способ 3: откройте Resources в Finder и дважды щёлкните DOCX.
- [ ] Способ 4: в Word выберите **File → Open Recent** и откройте файл из списка.
- [ ] Оставьте исходный документ открытым.

**В паспорт добавьте таблицу:**

| Способ | Команда или действие | Результат |
| --- | --- | --- |
| Меню Word | File → Open | Файл открыт |
| Клавиатура | ⌘O | Файл открыт |
| Finder | Двойной щелчок | Файл открыт |
| Недавние | File → Open Recent | Файл найден / список недоступен |

## Шаг 4. Изучить окно Word

- [ ] Найдите системную строку меню macOS.
- [ ] Найдите меню Word и File.
- [ ] Найдите строку заголовка и имя документа.
- [ ] Найдите AutoSave, если он отображается.
- [ ] Найдите поле Search.
- [ ] Найдите ленту, вкладки и группы команд.
- [ ] Найдите панель быстрого доступа.
- [ ] Найдите рабочую область, полосы прокрутки, строку состояния и масштаб.
- [ ] В паспорте вставьте временную таблицу 2×2.
- [ ] Щёлкните внутри таблицы и найдите контекстную вкладку.
- [ ] Удалите временную таблицу.

**В паспорт добавьте таблицу:**

| Элемент | Где расположен | Для чего нужен |
| --- | --- | --- |
| Строка меню macOS | Верх экрана | Доступ к меню Word, File, View и Window |
| Лента | Верх окна Word | Основные команды по вкладкам |
| Строка состояния | Низ окна | Страница, число слов, язык и масштаб |
| Контекстная вкладка | Появляется при выборе объекта | Команды выбранного объекта |

Дополните таблицу найденными элементами. Отдельно запишите: «В macOS нет Windows-представления Backstage и окна File → Options; настройки открываются через Word → Preferences/Settings».

## Шаг 5. Освоить ленту

- [ ] По очереди откройте вкладки Home, Insert, Layout, References, Review и View.
- [ ] Ничего не изменяйте; сравните группы команд.
- [ ] Нажмите **⌘⌥R** и убедитесь, что лента свернулась.
- [ ] Нажмите **⌘⌥R** повторно и верните ленту.
- [ ] Проверьте стрелку сворачивания справа на ленте.
- [ ] Перейдите между элементами ленты клавишами Tab и Shift+Tab.
- [ ] Если Tab не перемещает фокус, включите полный доступ с клавиатуры в настройках macOS.

**В паспорт запишите:**

> Лента сворачивается сочетанием ⌘⌥R. Windows-KeyTips через Alt в macOS отсутствуют; для навигации используются Tab, Shift+Tab и стрелки.

## Шаг 6. Найти команды

- [ ] Щёлкните поле Search в верхней части Word или откройте меню Help.
- [ ] Найдите команду «Ruler».
- [ ] Найдите «Navigation Pane».
- [ ] Найдите «New Window».
- [ ] Найдите «Zoom».
- [ ] Для каждой команды проверьте, что результат относится к Word, но пока не запускайте опасные действия.
- [ ] Нажмите **⌘F** и убедитесь, что это поиск текста в документе, а не поиск команды.

**В паспорт добавьте таблицу:**

| Искомая команда | Найдена через | Результат |
| --- | --- | --- |
| Ruler | Search / Help | Найдена / не найдена |
| Navigation Pane | Search / Help | Найдена / не найдена |
| New Window | Search / Help | Найдена / не найдена |
| Zoom | Search / Help | Найдена / не найдена |

## Шаг 7. Проверить контекстное меню

- [ ] Выделите слово и откройте меню правым щелчком.
- [ ] Повторите через **Control + щелчок**.
- [ ] Если используется трекпад, повторите двухпальцевым нажатием.
- [ ] Попробуйте **Shift+F10**; на MacBook при необходимости добавьте Fn.
- [ ] Сравните меню обычного текста и таблицы или рисунка.
- [ ] Закройте меню через Esc, ничего не меняя.

**В паспорт добавьте две строки:**

| Объект | Команды, характерные для объекта |
| --- | --- |
| Текст | Например, шрифт, абзац, поиск |
| Таблица или рисунок | Две реально найденные команды |

## Шаг 8. Настроить панель быстрого доступа

- [ ] Откройте **Word → Preferences/Settings → Ribbon & Toolbar**.
- [ ] Перейдите к настройкам Quick Access Toolbar.
- [ ] Попробуйте добавить Show/Hide ¶.
- [ ] Попробуйте добавить команду печати.
- [ ] Попробуйте добавить New Window.
- [ ] Измените порядок добавленных команд.
- [ ] Удалите одну команду и добавьте её обратно.
- [ ] Закройте настройки и проверьте панель.

**В паспорт добавьте таблицу:**

| Команда | Добавлена | Примечание |
| --- | :---: | --- |
| Show/Hide ¶ | Да / Нет | Причина, если недоступна |
| Print | Да / Нет | Точное название команды |
| New Window | Да / Нет | Причина, если недоступна |

## Шаг 9. Создать вкладку WORD PRO

- [ ] Откройте **Word → Preferences/Settings → Ribbon & Toolbar**.
- [ ] На вкладке Ribbon добавьте новую пользовательскую вкладку.
- [ ] Назовите её **WORD PRO**.
- [ ] Создайте группы «Навигация», «Контроль» и «Окна».
- [ ] В «Навигацию» добавьте доступную команду поиска или навигации.
- [ ] В «Контроль» добавьте Show/Hide ¶ и Word Count, если они доступны.
- [ ] В «Окна» добавьте New Window или другую доступную команду окон.
- [ ] Сохраните настройки и убедитесь, что вкладка появилась.
- [ ] Проверьте, есть ли команда экспорта настроек.

**В паспорт добавьте таблицу:**

| Группа | Добавленные команды |
| --- | --- |
| Навигация | Перечислите фактические команды |
| Контроль | Перечислите фактические команды |
| Окна | Перечислите фактические команды |

Если экспорта нет, запишите: **«Экспорт .exportedUI в установленной версии Word для macOS не обнаружен»**. Можно приложить снимок экрана вкладки WORD PRO.

## Шаг 10. Проверить строку состояния

- [ ] Найдите строку состояния внизу окна.
- [ ] Найдите номер текущей страницы.
- [ ] Найдите число слов.
- [ ] Найдите язык проверки, если он показан.
- [ ] Найдите масштаб.
- [ ] Щёлкните число слов и откройте подробную статистику.
- [ ] Выделите один абзац и посмотрите, изменилось ли число слов.
- [ ] Снимите выделение.

**В паспорт добавьте таблицу только с реально видимыми элементами:**

| Показатель | Что показывает | Проверка |
| --- | --- | --- |
| Страница | Текущую страницу и общее число | Значение записано |
| Число слов | Слова в документе или выделении | Изменилось при выделении |
| Масштаб | Процент отображения | Текущее значение |

## Шаг 11. Включить линейки

- [ ] Переключитесь в **View → Print Layout**.
- [ ] Выберите **View → Ruler**.
- [ ] Если вертикальной линейки нет, откройте **Word → Preferences/Settings → View**.
- [ ] Включите Vertical ruler.
- [ ] Откройте **Word → Preferences/Settings → General**.
- [ ] В Show measurements in units of временно выберите millimeters.
- [ ] Посмотрите на линейку и верните centimeters.
- [ ] Щёлкните обычный абзац.
- [ ] Перетащите маркер первой строки, удерживая Option.
- [ ] Сразу отмените изменение через **⌘Z**.

**В паспорт запишите:**

> Режим: Print Layout. Горизонтальная линейка: включена. Вертикальная линейка: включена / недоступна. Единицы: centimeters. Option при перетаскивании использован для точной регулировки.

## Шаг 12. Показать непечатаемые знаки

- [ ] Нажмите ¶ на вкладке Home.
- [ ] Нажмите **⌘8**, чтобы выключить знаки.
- [ ] Нажмите **⌘8** повторно, чтобы включить их.
- [ ] Откройте **Word → Preferences/Settings → View**.
- [ ] Найдите Show Non-Printing Characters.
- [ ] Проверьте способ через панель быстрого доступа, если ¶ была добавлена.
- [ ] Оставьте знаки включёнными.

**В паспорт добавьте таблицу:**

| Знак | Что означает |
| --- | --- |
| Точка между словами | Пробел |
| ¶ | Конец абзаца |
| Стрелка | Табуляция |
| Изогнутая стрелка или подпись разрыва | Разрыв строки, страницы или раздела |

## Шаг 13. Использовать навигацию и поиск

- [ ] Выберите **View → Navigation Pane**, если команда доступна.
- [ ] Откройте поиск сочетанием **⌘F**.
- [ ] Найдите фразу **КОНТРОЛЬНАЯ ФРАЗА БЕТА**.
- [ ] Найдите слово «мастер-копия».
- [ ] В области заголовков найдите раздел 7.3 «Мастер-копия», если заголовки показаны.
- [ ] Проверьте представление страниц, если оно доступно.
- [ ] Перейдите в начало через **⌘Home**; на MacBook — **⌘Fn←**.
- [ ] Перейдите в конец через **⌘End**; на MacBook — **⌘Fn→**.

**В паспорт запишите:**

> Поиск текста находит совпадения по словам. Навигация по заголовкам переходит между структурными разделами, которым назначены стили заголовков. Доступные вкладки области навигации: [перечислить].

## Шаг 14. Проверить режимы просмотра

- [ ] Включите Print Layout и осмотрите страницы и поля.
- [ ] Включите Web Layout и отметьте исчезновение печатной разбивки.
- [ ] Включите Outline и проверьте иерархию заголовков.
- [ ] Включите Draft и сравните представление с Print Layout.
- [ ] Включите Focus, если команда доступна, затем выйдите из него.
- [ ] Проверьте наличие отдельного Read Mode.
- [ ] Верните Print Layout.

**В паспорт добавьте таблицу:**

| Режим | Для чего удобен | Что изменилось | Доступен |
| --- | --- | --- | :---: |
| Print Layout | Подготовка к печати | Видны страницы и поля | Да |
| Web Layout | Просмотр непрерывного текста | Нет обычной разбивки | Да / Нет |
| Outline | Работа со структурой | Видны уровни заголовков | Да / Нет |
| Draft | Быстрое редактирование | Упрощено отображение | Да / Нет |
| Focus | Работа без лишних элементов | Интерфейс скрыт | Да / Нет |
| Read Mode | Проверка отличия от Windows | Описать результат | Да / Нет |

## Шаг 15. Проверить масштаб

- [ ] Ползунком установите 150 %.
- [ ] Ползунком установите 75 %.
- [ ] Нажмите **⌘0** и верните 100 %.
- [ ] Проверьте **⌘+** и **⌘−**.
- [ ] Проверьте **⌘ + прокрутка** мыши или трекпада.
- [ ] Откройте **View → Zoom**.
- [ ] Проверьте Page Width или One Page, если они доступны.
- [ ] Верните масштаб 100 %.

**В паспорт добавьте строку:**

> Проверены способы масштаба: [перечислить]. Финальное значение: 100 %. Масштаб изменяет только отображение, а не размер шрифта.

## Шаг 16. Поработать с окнами

- [ ] Откройте команду New Window через меню Window или View.
- [ ] В первом окне перейдите к началу документа.
- [ ] Во втором окне перейдите к разделу 9.
- [ ] Переключитесь вперёд через **⌘ + клавиша обратного апострофа** или **⌘F6**.
- [ ] Переключитесь назад через **⌘Shift + клавиша обратного апострофа** или **⌘ShiftF6**.
- [ ] Проверьте команды размещения в меню Window.
- [ ] Проверьте View Side by Side и Synchronous Scrolling, если они доступны.
- [ ] Выполните **View → Split** либо используйте разделитель над полосой прокрутки.
- [ ] Уберите разделение.
- [ ] Закройте лишнее окно, не закрывая второе.

**В паспорт добавьте таблицу:**

| Действие | Результат |
| --- | --- |
| New Window | Создано второе окно того же файла |
| Переключение окон | Использованные сочетания |
| Side by Side | Доступно / недоступно |
| Split | Две области одного окна созданы и убраны |

## Шаг 17. Изучить настройки безопасно

- [ ] Откройте **Word → Preferences/Settings**.
- [ ] Просмотрите General.
- [ ] Просмотрите View.
- [ ] Просмотрите Spelling & Grammar.
- [ ] Просмотрите Save.
- [ ] Просмотрите Ribbon & Toolbar.
- [ ] Найдите параметры безопасности или конфиденциальности.
- [ ] При необходимости откройте **System Settings → Privacy & Security**, но ничего не меняйте.
- [ ] Закройте настройки через Cancel, если изменения не требуются.

**В паспорт добавьте таблицу:**

| Раздел | За что отвечает | Что изменено |
| --- | --- | --- |
| General | Общие параметры и единицы | Единицы возвращены в сантиметры |
| View | Линейки и служебные знаки | Указать изменения |
| Spelling & Grammar | Проверка текста | Ничего |
| Save | Сохранение | Ничего |
| Ribbon & Toolbar | Лента и панель | Вкладка WORD PRO |
| Privacy & Security | Доступ и безопасность | Ничего |

Добавьте остальные реально доступные разделы.

## Шаг 18. Сохранить и проверить работу

- [ ] Верните Print Layout.
- [ ] Верните масштаб 100 %.
- [ ] Убедитесь, что единицы измерения — сантиметры.
- [ ] Оставьте линейку и непечатаемые знаки включёнными.
- [ ] Проверьте панель быстрого доступа и вкладку WORD PRO.
- [ ] Нажмите **⌘S** в паспорте.
- [ ] Закройте исходный документ через **⌘W**.
- [ ] Если Word предлагает сохранить случайные изменения исходника, выберите «Не сохранять».
- [ ] Закройте и повторно откройте паспорт.
- [ ] Проверьте, что все таблицы заполнены, а пропущенные функции объяснены.

**В конце паспорта напишите:**

> Практическая работа выполнена в Microsoft Word [версия] на macOS [версия]. Все доступные действия проверены. Недоступные или отличающиеся функции: [перечислить либо написать «нет»].
