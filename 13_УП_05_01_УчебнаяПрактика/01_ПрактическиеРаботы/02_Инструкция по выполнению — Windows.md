# Инструкция по выполнению практической работы №2 на Windows

<sub>[← К предмету](../README.md) · [Все предметы](../../README.md)</sub>

[← К описанию практической работы](%D0%9F%D1%80%D0%B0%D0%BA%D1%82%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B0%D1%8F%20%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0%20%E2%84%962%20%E2%80%94%20Microsoft%20Word%20%D0%BA%D0%B0%D0%BA%20%D1%80%D0%B0%D0%B1%D0%BE%D1%87%D0%B0%D1%8F%20%D1%81%D1%80%D0%B5%D0%B4%D0%B0.md)

Эта инструкция предназначена для настольной версии Microsoft Word на Windows. Выполняйте пункты сверху вниз и отмечайте каждое завершённое действие.

> [!IMPORTANT]
> **Important**
> Навигационный документ используется только как материал для упражнений. Не сохраняйте в нём экспериментальные изменения. Если команда отсутствует, запишите это как отличие установленной версии Word.

## Как заполнять паспорт

В начале паспорта создайте раздел «Сведения о выполнении»:

| Поле | Что записать |
| --- | --- |
| ФИО | Фамилия, имя и отчество |
| Группа | Номер или название группы |
| Дата | Дата выполнения в формате ДД.ММ.ГГГГ |
| Операционная система | Выпуск Windows и номер версии |
| Word | Выпуск, версия, сборка и разрядность |
| Язык интерфейса | Русский, английский или другой |

После каждого шага добавляйте подзаголовок «Шаг N» и фиксируйте результат в указанном ниже виде. Если функция отсутствует, пишите: **«Не обнаружена в Word версии … на Windows …»**.

## Шаг 1. Подготовить папки и паспорт

- [ ] Откройте Проводник.
- [ ] Создайте папку **WORD_PRO_ФамилияИмя**.
- [ ] Внутри создайте **Блок_01**, а в ней — папки **ПР01** и **Resources**.
- [ ] Скопируйте [навигационный документ](%D0%9B%D0%B5%D0%BA%D1%86%D0%B8%D1%8F3_%D0%9D%D0%B0%D0%B2%D0%B8%D0%B3%D0%B0%D1%86%D0%B8%D0%BE%D0%BD%D0%BD%D1%8B%D0%B9_%D0%B4%D0%BE%D0%BA%D1%83%D0%BC%D0%B5%D0%BD%D1%82_%D0%AD%D0%94%D0%9E.docx) в Resources.
- [ ] Откройте Word и нажмите **Ctrl+N** либо выберите **Файл → Создать → Пустой документ**.
- [ ] Введите заголовок «Паспорт рабочей среды Microsoft Word».
- [ ] Нажмите **Ctrl+S** и сохраните документ в ПР01 под именем **ПР01_Паспорт_среды_Фамилия.docx**.
- [ ] Закройте паспорт через **Ctrl+W**, откройте его снова и убедитесь, что файл сохранился.

**В паспорт:** заполните таблицу «Сведения о выполнении». Поля версии Word пока можно оставить пустыми.

## Шаг 2. Определить версию Word

- [ ] Откройте **Файл → Учётная запись**.
- [ ] В разделе «Сведения о продукте» найдите название выпуска.
- [ ] Нажмите «О программе Word».
- [ ] Запишите номер версии, сборку и разрядность.
- [ ] Закройте информационное окно без изменения настроек.

**В паспорт запишите одной строкой:**

> Microsoft Word: [выпуск], версия [номер], сборка [номер], [32/64]-разрядная, язык интерфейса [язык].

## Шаг 3. Открыть исходный документ разными способами

- [ ] Способ 1: выберите **Файл → Открыть → Обзор**, найдите Resources и откройте DOCX.
- [ ] Закройте только документ сочетанием **Ctrl+W**.
- [ ] Способ 2: нажмите **Ctrl+O** и откройте тот же файл.
- [ ] Снова закройте документ.
- [ ] Способ 3: нажмите **Ctrl+F12** и откройте файл.
- [ ] Снова закройте документ.
- [ ] Способ 4: откройте Resources в Проводнике и дважды щёлкните DOCX.
- [ ] Проверьте **Файл → Открыть → Последние**.
- [ ] Если доступно закрепление, закрепите файл и затем снимите закрепление.
- [ ] Оставьте исходный документ открытым.

**В паспорт добавьте таблицу:**

| Способ | Команда или действие | Результат |
| --- | --- | --- |
| Меню Word | Файл → Открыть → Обзор | Файл открыт |
| Клавиатура 1 | Ctrl+O | Файл открыт |
| Клавиатура 2 | Ctrl+F12 | Файл открыт |
| Проводник | Двойной щелчок | Файл открыт |
| Недавние | Файл → Открыть → Последние | Найден / список недоступен |

## Шаг 4. Изучить окно Word

- [ ] Найдите строку заголовка и имя документа.
- [ ] Найдите поле Search.
- [ ] Найдите панель быстрого доступа.
- [ ] Найдите вкладку «Файл».
- [ ] Найдите ленту, вкладки и группы команд.
- [ ] Найдите кнопку запуска диалога в группе «Шрифт» или «Абзац».
- [ ] Найдите рабочую область и полосу прокрутки.
- [ ] Найдите строку состояния, переключатели вида и масштаб.
- [ ] В паспорте вставьте временную таблицу 2×2.
- [ ] Щёлкните внутри таблицы и найдите контекстную вкладку.
- [ ] Удалите временную таблицу.

**В паспорт добавьте таблицу:**

| Элемент | Где расположен | Для чего нужен |
| --- | --- | --- |
| Строка заголовка | Верх окна | Имя документа и управление окном |
| Панель быстрого доступа | Над или под лентой | Часто используемые команды |
| Лента | Верх окна | Команды по вкладкам и группам |
| Строка состояния | Низ окна | Страница, слова, язык, вид и масштаб |
| Контекстная вкладка | Появляется при выборе объекта | Команды выбранного объекта |

## Шаг 5. Освоить ленту

- [ ] По очереди откройте вкладки «Главная», «Вставка», «Макет», «Ссылки», «Рецензирование» и «Вид».
- [ ] Ничего не изменяйте; сравните группы команд.
- [ ] Нажмите **Alt** и найдите KeyTips.
- [ ] По показанным буквам откройте вкладку «Вид».
- [ ] Нажмите Esc до исчезновения KeyTips.
- [ ] Повторите через **F10**.
- [ ] Нажмите **Ctrl+F1** и сверните ленту.
- [ ] Нажмите **Ctrl+F1** повторно и верните ленту.
- [ ] Проверьте двойной щелчок по активной вкладке.

**В паспорт запишите:**

> Лента проверена мышью и клавиатурой. KeyTips вызываются через Alt и F10. Лента сворачивается через Ctrl+F1 и двойной щелчок по вкладке.

## Шаг 6. Найти команды

- [ ] Нажмите **Alt+Q**.
- [ ] Найдите «линейка».
- [ ] Найдите «область навигации».
- [ ] Найдите «новое окно».
- [ ] Найдите «масштаб».
- [ ] Перед выбором проверяйте, что результат является командой, а не справочной статьёй.

**В паспорт добавьте таблицу:**

| Искомая команда | Текст запроса | Найдена |
| --- | --- | :---: |
| Линейка | линейка | Да / Нет |
| Область навигации | область навигации | Да / Нет |
| Новое окно | новое окно | Да / Нет |
| Масштаб | масштаб | Да / Нет |

Ниже запишите формулу: **Alt+Q → название функции → проверка результата → выполнение команды**.

## Шаг 7. Проверить контекстное меню

- [ ] Выделите слово мышью.
- [ ] Откройте контекстное меню правой кнопкой.
- [ ] Закройте его через Esc.
- [ ] Выделите другое слово клавишами Shift+стрелки.
- [ ] Откройте меню через **Shift+F10**.
- [ ] Сравните меню текста и таблицы или рисунка.
- [ ] Ничего не форматируйте.

**В паспорт добавьте две строки:**

| Объект | Команды, характерные для объекта |
| --- | --- |
| Текст | Например, шрифт, абзац, поиск |
| Таблица или рисунок | Две реально найденные команды |

## Шаг 8. Настроить панель быстрого доступа

- [ ] Откройте меню панели или **Файл → Параметры → Панель быстрого доступа**.
- [ ] Добавьте «Отобразить все знаки» (¶).
- [ ] Добавьте «Быстрая печать».
- [ ] Добавьте «Новое окно».
- [ ] При необходимости выберите «Все команды».
- [ ] Добавьте разделитель, если он доступен.
- [ ] Измените порядок команд.
- [ ] Переместите панель ниже ленты и затем верните в удобное положение.
- [ ] Удалите одну команду и добавьте её обратно.
- [ ] Нажмите Alt и вызовите безопасную команду панели через KeyTip.

**В паспорт добавьте таблицу:**

| Команда | Добавлена | Способ добавления |
| --- | :---: | --- |
| Отобразить все знаки | Да / Нет | Контекстное меню / параметры |
| Быстрая печать | Да / Нет | Параметры |
| Новое окно | Да / Нет | Параметры |

## Шаг 9. Создать вкладку WORD PRO

- [ ] Откройте **Файл → Параметры → Настроить ленту**.
- [ ] Нажмите «Создать вкладку».
- [ ] Назовите её **WORD PRO**.
- [ ] Создайте группы «Навигация», «Контроль» и «Окна».
- [ ] В «Навигацию» добавьте доступную команду поиска или области навигации.
- [ ] В «Контроль» добавьте ¶ и Word Count или «Статистика».
- [ ] В «Окна» добавьте «Новое окно», «Переключить окна» или «Рядом».
- [ ] Нажмите OK и проверьте вкладку.
- [ ] Вернитесь в настройку ленты.
- [ ] Выберите **Импорт/экспорт → Экспортировать все настройки**.
- [ ] Сохраните файл как **WORD_PRO_Фамилия.exportedUI** в ПР01.
- [ ] Не импортируйте файл обратно.

**В паспорт добавьте таблицу:**

| Группа | Добавленные команды |
| --- | --- |
| Навигация | Перечислите фактические команды |
| Контроль | Перечислите фактические команды |
| Окна | Перечислите фактические команды |

Ниже укажите: **Экспорт настроек: выполнен / команда недоступна. Имя файла: …**

## Шаг 10. Настроить строку состояния

- [ ] Щёлкните правой кнопкой по пустой части строки состояния.
- [ ] Включите номер страницы.
- [ ] Включите число слов.
- [ ] Включите язык проверки.
- [ ] Включите ползунок масштаба.
- [ ] Включите кнопки режимов просмотра.
- [ ] Включите раздел или номер строки, если они доступны.
- [ ] Выделите один абзац и посмотрите, изменилось ли число слов.
- [ ] Снимите выделение.

**В паспорт добавьте минимум пять строк:**

| Показатель | Что показывает | Проверка |
| --- | --- | --- |
| Номер страницы | Текущую страницу и общее число | Значение записано |
| Число слов | Слова в документе или выделении | Изменилось при выделении |
| Язык | Язык проверки текста | Значение записано |
| Масштаб | Процент отображения | Значение записано |
| Режим просмотра | Текущий вид документа | Кнопки найдены |

## Шаг 11. Включить линейки

- [ ] Выберите **Вид → Разметка печати**.
- [ ] Включите **Вид → Линейка**.
- [ ] Если вертикальной линейки нет, откройте **Файл → Параметры → Дополнительно**.
- [ ] В разделе «Экран» включите вертикальную линейку в режиме разметки печати.
- [ ] Найдите «Показывать единицы измерения в».
- [ ] Временно выберите миллиметры.
- [ ] Посмотрите на линейки и верните сантиметры.
- [ ] Щёлкните обычный абзац.
- [ ] Перетащите маркер первой строки, удерживая Alt.
- [ ] Сразу отмените изменение через **Ctrl+Z**.

**В паспорт запишите:**

> Режим: Разметка печати. Горизонтальная линейка: включена. Вертикальная линейка: включена / недоступна. Единицы: сантиметры. Alt при перетаскивании показывает точные измерения.

## Шаг 12. Показать непечатаемые знаки

- [ ] Нажмите ¶ на вкладке «Главная».
- [ ] Нажмите **Ctrl+Shift+8**, чтобы выключить знаки.
- [ ] Нажмите **Ctrl+Shift+8** повторно, чтобы включить их.
- [ ] Проверьте кнопку ¶ на панели быстрого доступа.
- [ ] Нажмите Alt и вызовите ¶ через показанный KeyTip.
- [ ] Оставьте знаки включёнными.

**В паспорт добавьте таблицу:**

| Знак | Что означает |
| --- | --- |
| Точка между словами | Пробел |
| ¶ | Конец абзаца |
| Стрелка | Табуляция |
| Изогнутая стрелка или подпись разрыва | Разрыв строки, страницы или раздела |

## Шаг 13. Использовать навигацию и поиск

- [ ] Откройте **Вид → Область навигации**.
- [ ] Закройте область.
- [ ] Нажмите **Ctrl+F** и откройте её повторно.
- [ ] В заголовках найдите раздел 7.3 «Мастер-копия».
- [ ] В представлении страниц перейдите по нескольким эскизам.
- [ ] Найдите фразу **КОНТРОЛЬНАЯ ФРАЗА БЕТА**.
- [ ] Найдите слово «мастер-копия» и просмотрите несколько совпадений.
- [ ] Нажмите **Ctrl+Home** для перехода в начало.
- [ ] Нажмите **Ctrl+End** для перехода в конец.
- [ ] Вернитесь к разделу 1 через заголовки.

**В паспорт запишите:**

> Поиск текста находит совпадения по словам. Навигация по заголовкам переходит между структурными разделами, которым назначены стили заголовков.

## Шаг 14. Проверить режимы просмотра

- [ ] Включите «Разметка печати» и осмотрите страницы и поля.
- [ ] Включите «Режим чтения» и затем выйдите из него.
- [ ] Включите «Веб-документ».
- [ ] Включите «Структура», но не перемещайте разделы.
- [ ] Закройте режим структуры.
- [ ] Включите «Черновик».
- [ ] Включите «Фокусировка», если она доступна.
- [ ] Верните «Разметка печати».

**В паспорт добавьте таблицу:**

| Режим | Для чего удобен | Что изменилось | Доступен |
| --- | --- | --- | :---: |
| Разметка печати | Подготовка к печати | Видны страницы и поля | Да |
| Режим чтения | Чтение | Интерфейс упрощён | Да / Нет |
| Веб-документ | Непрерывный текст | Нет обычной разбивки | Да / Нет |
| Структура | Работа с заголовками | Видны уровни | Да / Нет |
| Черновик | Быстрое редактирование | Упрощено отображение | Да / Нет |
| Фокусировка | Работа без лишних элементов | Интерфейс скрыт | Да / Нет |

## Шаг 15. Проверить масштаб

- [ ] Ползунком установите 150 %.
- [ ] Ползунком установите 75 %.
- [ ] Верните 100 %.
- [ ] Проверьте кнопки + и −.
- [ ] Щёлкните значение масштаба и откройте диалог, если оно активно.
- [ ] В **Вид → Масштаб** проверьте 200 %, 100 %, «Одна страница», «Несколько страниц» и «По ширине страницы».
- [ ] Проверьте **Ctrl + колесо мыши**.
- [ ] Если доступно «Из стороны в сторону», включите его и затем верните вертикальное перемещение.
- [ ] Верните масштаб 100 %.

**В паспорт добавьте строку:**

> Проверены способы масштаба: [перечислить]. Финальное значение: 100 %. Масштаб изменяет только отображение, а не размер шрифта.

## Шаг 16. Поработать с окнами

- [ ] Выберите **Вид → Новое окно**.
- [ ] В первом окне перейдите к разделу 1.
- [ ] Во втором окне перейдите к разделу 9.
- [ ] Переключитесь вперёд через **Ctrl+F6**.
- [ ] Переключитесь назад через **Ctrl+Shift+F6**.
- [ ] Проверьте **Вид → Переключить окна**.
- [ ] Откройте рядом паспорт и выберите **Вид → Рядом**.
- [ ] Включите и выключите синхронную прокрутку.
- [ ] Проверьте «Упорядочить всё».
- [ ] Выполните **Вид → Разделить**.
- [ ] Уберите разделение.
- [ ] Закройте лишнее окно через Ctrl+W.

**В паспорт добавьте таблицу:**

| Действие | Результат |
| --- | --- |
| Новое окно | Создано второе окно того же файла |
| Переключение | Ctrl+F6 и Ctrl+Shift+F6 проверены |
| Рядом | Два документа размещены рядом |
| Синхронная прокрутка | Включена и выключена |
| Разделить | Две области одного окна созданы и убраны |

- [ ] Откройте **Файл → Параметры**.
- [ ] Просмотрите «Общие».
- [ ] Просмотрите «Экран».
- [ ] Просмотрите «Правописание».
- [ ] Просмотрите «Сохранение».
- [ ] Просмотрите «Язык».
- [ ] Просмотрите «Дополнительно».
- [ ] Просмотрите «Настроить ленту».
- [ ] Просмотрите «Панель быстрого доступа».
- [ ] Откройте «Центр управления безопасностью», но ничего не меняйте.
- [ ] Нажмите «Отмена», если дополнительные изменения не требуются.

**В паспорт добавьте таблицу:**

| Раздел | За что отвечает | Что изменено |
| --- | --- | --- |
| Общие | Интерфейс и персонализация | Ничего |
| Экран | Отображение и служебные знаки | Указать изменения |
