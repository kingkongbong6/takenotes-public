# Практическая работа №2 — Microsoft Word как рабочая среда

<sub>[← К предмету](../README.md) · [Все предметы](../../README.md)</sub>

## Тема

Интерфейс Microsoft Word, лента, поиск команд, панель быстрого доступа, строка состояния, линейки, непечатаемые знаки, режимы просмотра, масштаб, навигация и работа с несколькими окнами.

Исходная методичка рассчитана на настольную версию Microsoft Word для Windows. Ниже также приведена адаптированная последовательность для Word в macOS. Основной ориентир — Microsoft 365 и Word 2024; названия, расположение и доступность отдельных команд могут различаться между выпусками и каналами обновления.

## Цель и ожидаемый результат

Цель работы — настроить Word как удобную рабочую среду для работы с длинными документами и освоить несколько способов вызова основных команд.

После выполнения нужно уметь:

- ориентироваться в окне Word и объяснять назначение его основных элементов;
- работать с лентой мышью, клавиатурой и KeyTips;
- находить команды через поиск Word;
- настраивать панель быстрого доступа, пользовательскую вкладку ленты и строку состояния;
- включать линейки и непечатаемые знаки;
- использовать область навигации, поиск, режимы просмотра и масштаб;
- работать с несколькими окнами одного документа и с двумя документами рядом;
- различать настройки приложения, документа, файла и окна.

Итог работы — настроенная среда Word и заполненный документ «Паспорт рабочей среды Microsoft Word». В Windows также требуется экспорт настроек ленты и панели быстрого доступа, если эта возможность доступна. В macOS отсутствие экспорта `.exportedUI` нужно зафиксировать в паспорте, а не заменять выдуманным файлом.

## Что требуется подготовить

По методичке рабочая папка имеет следующую структуру:

```text
WORD_PRO_ФамилияИмя/
└── Блок_01/
    ├── ПР01/
    │   ├── ПР01_Паспорт_среды_Фамилия.docx
    │   └── WORD_PRO_Фамилия.exportedUI
    └── Resources/
        └── ПР01_Навигационный_документ_ЭДО.docx
```

Файл `.exportedUI` нужен только для демонстрации переноса настроек Word. Он не содержит документы и создаётся лишь в том случае, если экспорт доступен в установленной версии программы.

## Четыре уровня Word

| Уровень | Что относится к уровню | Примеры |
| --- | --- | --- |
| Приложение | Общие настройки Word | язык интерфейса, лента, панель быстрого доступа, часть параметров |
| Документ | Структура и содержимое, сохранённые в документе | текст, стили, таблицы, разделы, колонтитулы |
| Файл | Физический объект хранения | имя, расширение, путь, формат DOCX, локальное или облачное размещение |
| Окно | Текущее представление открытого документа | масштаб, положение прокрутки, новое окно того же документа |

Важно помнить: изменение масштаба не меняет размер шрифта, настройка ленты не сохраняется внутри DOCX, а новое окно того же документа не создаёт копию файла.

## Финальное состояние Word

Общее для обеих систем:

- открыт режим разметки печати;
- масштаб возвращён к 100 %;
- линейка включена, единицы измерения — сантиметры;
- непечатаемые знаки включены;
- панель быстрого доступа содержит все поддерживаемые команды;
- пользовательская вкладка `WORD PRO` присутствует;
- исходный навигационный документ не содержит сохранённых изменений;
- паспорт сохранён, закрыт и успешно открыт повторно.

Платформенные проверки:

| Windows | macOS |
| --- | --- |
| KeyTips проверены через `Alt` и `F10` | Вместо KeyTips проверена клавиатурная навигация и записано отличие |
| Масштаб 100 %, перемещение страниц по вертикали | Масштаб 100 %; режим перемещения записан по фактической доступности |
| Строка состояния настроена контекстным меню | Записаны реально видимые элементы строки состояния |
| Создан `WORD_PRO_Фамилия.exportedUI`, если экспорт доступен | Отсутствие экспорта зафиксировано; при необходимости приложен снимок настройки |

## Содержание паспорта среды

В документе `ПР01_Паспорт_среды_Фамилия.docx` должны быть:

- ФИО, группа и дата выполнения;
- операционная система, фактическая версия и сборка Word, язык интерфейса;
- таблица элементов интерфейса и их назначения;
- описание резервного поиска: `Alt+Q` в Windows либо поле Search/меню Help в macOS;
- вывод о контекстном меню и примеры команд;
- минимум пять показателей строки состояния с пояснениями либо список всех доступных показателей, если их меньше;
- таблица непечатаемых знаков минимум из четырёх элементов;
- краткое описание режимов просмотра;
- различие между навигацией по заголовкам и текстовым поиском;
- таблица минимум по восьми разделам параметров Word или по всем доступным разделам в macOS;
- отдельный раздел «Отличия моей версии», где перечислены отсутствующие или переименованные команды.

## Основные сочетания клавиш

| Действие | Windows | macOS |
| --- | --- | --- |
| Новый документ | `Ctrl+N` | `⌘N` |
| Открыть документ | `Ctrl+O`, `Ctrl+F12` | `⌘O` |
| Сохранить | `Ctrl+S`, `Shift+F12` | `⌘S` |
| Закрыть документ | `Ctrl+W` | `⌘W` |
| Отменить действие | `Ctrl+Z` | `⌘Z` |
| Поиск текста | `Ctrl+F` | `⌘F` |
| Поиск команды | `Alt+Q` | поле Search или меню Help |
| Контекстное меню | `Shift+F10` | правый щелчок, `Control`+щелчок или `Shift+F10` |
| Свернуть или развернуть ленту | `Ctrl+F1` | `⌘⌥R` |
| Показать непечатаемые знаки | `Ctrl+Shift+8` | `⌘8` |
| Начало документа | `Ctrl+Home` | `⌘Home`; MacBook: `⌘Fn←` |
| Конец документа | `Ctrl+End` | `⌘End`; MacBook: `⌘Fn→` |
| Следующее окно Word | `Ctrl+F6` | <kbd>⌘</kbd> + <kbd>`</kbd> или `⌘+F6` |
| Предыдущее окно Word | `Ctrl+Shift+F6` | <kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>`</kbd> или `⌘+Shift+F6` |
| Масштаб мышью | `Ctrl`+колесо | `⌘`+прокрутка |
| Масштаб 100 % | через строку состояния или «Вид → Масштаб» | `⌘0` |
| KeyTips | `Alt` или `F10` | прямого аналога Windows нет |

> [!NOTE]
> **Note**
> На Mac функциональные клавиши могут требовать `Fn`. Некоторые сочетания конфликтуют с системными настройками macOS; в этом случае используйте меню Word и запишите отличие.
