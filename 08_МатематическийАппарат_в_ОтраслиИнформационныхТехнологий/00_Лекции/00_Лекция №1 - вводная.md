# Лекция №1 — Матрицы

<sub>[← К предмету](../README.md) · [Все предметы](../../README.md)</sub>

## Основные определения

<details open>
<summary><strong>📋 Матрица</strong></summary>

**Матрица** — прямоугольная таблица чисел.

- горизонтальные ряды называются **строками**;
- вертикальные ряды называются **столбцами**;
- каждое отдельное число называется **элементом матрицы**.

</details>

Матрицу обозначают заглавной латинской буквой, а её элементы — соответствующей строчной буквой с двумя индексами:

$$
A = (a_{ij})_{m \times n},
$$

где:

- $m$ — количество строк;
- $n$ — количество столбцов;
- $i$ — номер строки элемента;
- $j$ — номер столбца элемента;
- $a_{ij}$ — элемент, расположенный в строке $i$ и столбце $j$.

> [!NOTE]
> **Размер матрицы**
> Размер матрицы записывается как $m \times n$, то есть **количество строк × количество столбцов**.

Элементами матрицы могут быть целые и дробные, положительные и отрицательные числа, а также константы.

## Виды матриц

<details>
<summary><strong>🧩 Основные виды матриц</strong></summary>

| Вид | Условие или определение |
| --- | --- |
| **Квадратная** | Количество строк равно количеству столбцов: $m = n$. |
| **Прямоугольная** | Количество строк не равно количеству столбцов: $m \ne n$. |
| **Матрица-строка** | Содержит одну строку: $m = 1$. |
| **Матрица-столбец** | Содержит один столбец: $n = 1$. |
| **Нулевая** | Все элементы равны нулю. |
| **Диагональная** | Все элементы вне главной диагонали равны нулю. |
| **Единичная** | Элементы главной диагонали равны единице, остальные — нулю. |
| **Треугольная** | Все элементы выше или ниже главной диагонали равны нулю. |

</details>

## Сложение матриц

Складывать можно только матрицы **одинакового размера** $m \times n$.

Если

$$
A = (a_{ij}), \qquad B = (b_{ij}),
$$

то сумма матриц вычисляется поэлементно:

$$
A + B = C, \qquad c_{ij} = a_{ij} + b_{ij}.
$$

> [!WARNING]
> **Условие сложения**
> Для сложения матриц должны совпадать и количество строк, и количество столбцов.
